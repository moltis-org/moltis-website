# moltis-website

Landing page for [Moltis](https://moltis.org), inspired by [OpenClaw](https://github.com/penso/moltis).

- Cloud deploy section: https://moltis.org/#cloud-deploy

---

February 2026: Moltis hit [the front page of Hacker News](https://news.ycombinator.com/item?id=46993587) and crossed 1k GitHub stars in its first week. It's 150k lines of Rust, zero `unsafe`, no runtime dependencies — built with care, not generated. If social proof is helpful: I'm [Fabien Penso](https://pen.so), I've been shipping production systems since 1998 — starting with [LinuxFr.org](https://linuxfr.org) (France's largest Linux community, still running today), scaling services to 100M+ users, and most recently building the fastest Rust-based Cosmos indexer. Please open an issue for any friction at all — I'm focused on making Moltis excellent, and the biggest gap is understanding how others experience using it.
