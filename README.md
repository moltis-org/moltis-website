# moltis-website

Landing page for [Moltis](https://moltis.org), inspired by [OpenClaw](https://github.com/penso/moltis).

- Cloud deploy section: https://moltis.org/#cloud-deploy

---

February 2026: Moltis hit [the front page of Hacker News](https://news.ycombinator.com/item?id=46993587) and crossed 1k GitHub stars in its first week. It's 150k lines of Rust, zero `unsafe`, no runtime dependencies — built with care, not generated. If social proof is helpful: I'm [Fabien Penso](https://pen.so), I founded [LinuxFr.org](https://linuxfr.org) in 1998 (France's largest Linux community, still running 25+ years later), scaled Rails at [Causes](https://en.wikipedia.org/wiki/Causes_(company)) to 200M+ users, rewrote Stuart's entire backend from PHP to Ruby before its acquisition by La Poste, and built Beam's E2EE encryption API in Rust. Please open an issue for any friction at all — I'm focused on making Moltis excellent, and the biggest gap is understanding how others experience using it.
